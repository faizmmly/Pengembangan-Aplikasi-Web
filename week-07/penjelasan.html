Penjelasan Konsep & Komponen React

Detail implementasi Component-Based UI Development pada aplikasi AgendaKu.

1. React Components (Arsitektur Komponen)

Aplikasi dipecah ke dalam beberapa komponen modular yang terpisah di dalam folder src/components/ agar kode lebih bersih, terstruktur, dan mudah dirawat:

  • Header.tsx / Profil: Menampilkan identitas mahasiswa (Nama, NIM, kelas) secara dinamis.
  • StatsCard.tsx: Komponen kartu statistik untuk merangkum jumlah kegiatan harian dan tugas selesai.
  • TaskCard.tsx: Komponen kartu individual yang bersifat reusable untuk menampilkan rincian setiap kegiatan.
  • TaskForm.tsx: Formulir interaktif untuk menambah dan memperbarui data kegiatan.
  • CalendarView.tsx: Komponen kalender interaktif untuk memantau agenda berdasarkan tanggal.

2. Props (Pengiriman Data)

Props digunakan untuk mengirimkan data dari komponen induk (parent, seperti App.tsx) ke komponen anak (child). Contohnya, objek data kegiatan dikirimkan ke TaskCard agar komponen kartu dapat merender judul, mata kuliah, dan tenggat waktu secara spesifik.

3. State & useState (Pengelolaan Data Reaktif)

useState digunakan untuk menyimpan dan mengelola data yang dapat berubah secara dinamis di dalam aplikasi, seperti:

  • Menyimpan daftar array kegiatan (state tasks).
  • Mengelola status kategori filter yang sedang aktif (state currentFilter).
  • Menangani teks pencarian kata kunci secara real-time.
  • Mengontrol visibilitas modal konfirmasi dan notifikasi toast.

4. Event Handling & Rendering

Event Handling: Menangani interaksi pengguna seperti klik tombol aksi (ubah status, edit, hapus), pengisian formulir, dan pengetikan teks pada kolom pencarian.

List & Conditional Rendering: Menggunakan metode JavaScript .map() untuk merender array daftar kegiatan secara dinamis, serta menangani kondisi tampilan kosong (empty state) ketika data tidak ditemukan.
