✅ Checklist Pemenuhan Syarat Tugas 7

Ringkasan verifikasi seluruh kriteria praktikum pada aplikasi AgendaKu:

  • ✓
    Minimal 5 Komponen Terpisah Dipecah menjadi komponen modular (Header, StatsCards, FilterBar, ActivityCard, ModalForm, CalendarView).
  • ✓
    Props, State & Event Handling Komunikasi data parent-child via props bertipe TypeScript, useState, dan handler form/klik.
  • ✓
    Conditional Rendering & List Key Rendering dinamis status kegiatan, empty state, modal, serta .map() dengan atribut key unik.
  • ✓
    Fitur Interaktif Lengkap CRUD kegiatan (Tambah, Detail, Edit, Hapus), ubah status cepat, pencarian, filter jenis, dan sorting tanggal.
