Penjelasan Teknologi yang Digunakan

Ringkasan penggunaan Git, npm, TypeScript, Vite, dan environment variables pada aplikasi Pengelola Daftar Tugas Kuliah.

Git dan GitHub

Git mencatat riwayat perubahan kode lewat commit. Setiap fitur dikerjakan di branch sendiri, lalu digabung ke main lewat Pull Request. Jika dua branch mengubah baris yang sama, terjadi merge conflict yang diselesaikan manual. push mengirim commit ke GitHub dan pull mengambil pembaruan. File .gitignore mencegah node_modules dan .env terunggah.

npm

npm adalah pengelola paket Node.js. File package.json menyimpan daftar paket dan perintah.

BagianFungsi
dependenciesPaket yang dibutuhkan saat aplikasi berjalan.
devDependenciesPaket khusus pengembangan, misalnya TypeScript dan Vite.
scriptsnpm run dev, npm run build, npm run preview.
Semantic versioningFormat MAJOR.MINOR.PATCH. Contoh ^5.4.0 boleh naik minor dan patch, tidak boleh naik major.

TypeScript

TypeScript adalah JavaScript dengan tipe statis sehingga kesalahan tipe ketahuan sebelum aplikasi dijalankan. Yang dipakai di aplikasi:

  • Tipe primitif: string, number, boolean
  • Array: Task[]
  • Interface: Task, DetailedStats, Reminder
  • Type alias dan union type: Status, FilterStatus, SortBy
  • Generics: Store<T>, filterBy<T>, sortItems<T>

Compiler, transpiler, dan bundler

  • Compiler: menerjemahkan kode ke bentuk lain sambil memeriksa kesalahan. TypeScript memeriksa tipe pada tahap ini.
  • Transpiler: mengubah kode ke bahasa tingkat sama. TypeScript menjadi JavaScript yang bisa dibaca browser.
  • Bundler: menggabungkan banyak file modul (TS, CSS) menjadi sedikit file kecil untuk produksi.

Vite

Vite adalah build tool. Saat pengembangan, npm run dev menjalankan server cepat dengan hot reload. Saat npm run build, Vite mentranspile TypeScript, membundel file, dan menghasilkan folder dist/ yang siap di-deploy.

Environment variables

Konfigurasi disimpan di .env (tidak diunggah ke GitHub). .env.example menjadi template yang aman dibagikan.

VariabelFungsi
VITE_APP_NAMENama aplikasi
VITE_APP_VERSIONVersi aplikasi

Variabel berawalan VITE_ ikut tertanam di hasil build dan terlihat di browser, jadi hanya dipakai untuk data non-rahasia. Password dan API key tidak disimpan di sini.
