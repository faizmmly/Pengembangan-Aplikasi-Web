✅ Checklist Pemenuhan Syarat Tugas 8

Ringkasan verifikasi seluruh kriteria praktikum pada aplikasi TokoKita:

  • ✓
    Routing Lengkap Minimal 3 halaman, dynamic route (/produk/:id), dan nested layout route.
  • ✓
    4 Jenis State Management Context API (Keranjang & Favorit), URL Search Params, Server State (API), dan Form State.
  • ✓
    Data Fetching & UI States Integrasi DummyJSON API dengan penanganan Loading Skeleton, Error State, dan Empty State.
  • ✓
    Fitur Interaktif Lengkap Pencarian, filter kategori, sorting harga/rating, pagination, serta form ulasan bervalidasi.
  • ✓
    Arsitektur Modular & Custom Hook Komponen reusable terpisah, custom hook (useDebounce / useFetch), dan struktur folder rapi.
  • ✓
    Deploy SPA Tanpa 404 Konfigurasi vercel.json aktif sehingga refresh langsung di sub-rute berjalan normal.
