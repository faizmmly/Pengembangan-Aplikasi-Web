Penjelasan Arsitektur TokoKita

Pilih tab topik di bawah untuk melihat implementasi teknis React Router, State Management, API Fetching, dan struktur folder proyek.

Implementasi React Router (SPA Navigation)

Aplikasi menggunakan react-router-dom dengan pembagian rute terstruktur untuk navigasi tanpa muat ulang halaman:

  • Nested Layout Route: Membungkus halaman utama dengan komponen layout (Navbar & Footer persisten) menggunakan <Outlet />.
  • Halaman Statis Utama: Rute / (Beranda), /produk (Katalog), /favorit, /keranjang, dan /tentang.
  • Dynamic Route: Rute /produk/:id membaca parameter ID produk melalui hook useParams() untuk mengambil detail produk spesifik.
  • Fallback & Vercel Rewrite: Rute wildcard * menangani halaman tidak ditemukan, serta file vercel.json mengarahkan semua request ke index.html agar refresh langsung tidak menghasilkan error 404.

Empat Lapisan State Management

Pengelolaan state dipisahkan sesuai cakupan datanya agar tetap bersih dan mudah dirawat:

  • Global State (Context API): CartContext dan FavoriteContext menyimpan item keranjang, jumlah kuantitas, dan daftar favorit yang otomatis tersimpan ke localStorage.
  • URL State (useSearchParams): Kata kunci pencarian, filter kategori, urutan harga/rating, dan nomor halaman disimpan di query URL sehingga tautan hasil pencarian dapat dibagikan.
  • Server State: Menyimpan respons data produk, status isLoading, serta pesan error saat mengambil data dari API.
  • Form State: Mengelola input nama, rating bintang, dan komentar pada fitur ulasan produk lengkap dengan validasi panjang karakter sebelum dikirim.

Data Fetching, Error Handling & Custom Hooks

Data produk diambil secara asinkron dari REST API publik (DummyJSON Products API) melalui lapisan service terpisah:

  • Service Layer (services/productService.ts): Memusatkan pemanggilan fetch() untuk daftar produk, pencarian, kategori, dan detail produk.
  • Custom Hook: Mengenkapsulasi logika pencarian tertunda (debouncing) dan siklus pengambilan data asinkron agar komponen UI tetap fokus pada tampilan.
  • Resilient UI States: Menampilkan skeleton loader saat memuat, tampilan error state lengkap dengan tombol coba lagi saat jaringan offline, serta empty state jika filter tidak menemukan hasil.

Struktur Folder Modular

Kode sumber disusun berdasarkan pemisahan tanggung jawab (Separation of Concerns):

src/
├── components/   # Komponen UI reusable (Navbar, ProductCard, Skeleton, Pagination)
├── context/      # CartContext & FavoriteContext (Global State + localStorage)
├── hooks/        # Custom hooks (useDebounce, useProducts)
├── pages/        # Halaman rute (Home, Products, ProductDetail, Favorites, Cart, About)
├── services/     # Fungsi fetch API dan penanganan error HTTP
├── types/        # Definisi interface TypeScript (Product, CartItem, Review)
└── App.tsx       # Konfigurasi BrowserRouter dan Routes
